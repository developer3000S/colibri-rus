colibrì — это движок вывода с минимумом зависимостей для запуска больших моделей, состоящих из нескольких экспертов, на потребительском и гетерогенном оборудовании. Он рассматривает хранилище, ОЗУ и VRAM как одну иерархию вывода, сохраняя при этом семантику модели явной и измеримой.

<a id="what-you-can-run"></a>
## Что вы можете запустить

В настоящее время репозиторий включает движки для семейств GLM, DeepSeek, Kimi, Qwen, Inkling и OLMoE. Каждый движок использует один и тот же интерфейс `coli chat`, `coli serve` и `coli web`.

<Note>
colibrì — это движок вывода и исследовательская платформа, а не размещенный сервис. Пропускная способность сильно зависит от формата модели, размещения памяти, хранилища и размера подсказки.
</Note>

<a id="common-entry-points"></a>
## Общие точки входа

| Команда | Используйте его для |
| --- | --- |
| `coli chat` | Интерактивный вывод терминала |
| `coli serve` | Конечные точки HTTP, совместимые с OpenAI и Anthropic |
| `coli web` | Конечные точки HTTP и локальная веб-панель |
| `coli doctor` | Диагностика среды и зависимостей |
| `coli tune` | Измеренное размещение и настройка производительности |

<Warning>
Установите `COLI_API_KEY`, прежде чем предоставлять доступ к HTTP-серверу за пределами доверенного локального компьютера. Держите необработанные конечные точки браузера и телеметрии за одной границей сети.
</Warning>
