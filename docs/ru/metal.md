# Металлический бэкэнд (Apple Silicon, экспериментальный)

В Apple Silicon профиль декодирования привязан к matmul, а унифицированная память удаляет
налог на копирование PCIe, который удерживает экспертов по потоковой передаче CUDA на CPU — итак colibrì
имеет встроенную серверную часть Metal, на которой работает **routed-expert SwiGLU (пакетный,
нулевое копирование из блоков ОЗУ)**, **слитое внимание к декодированию** (полный уровень MLA
в одном командном буфере, S≤4) и **большие GEMM предварительного заполнения** на графическом процессоре.
Декодирование выполняется с точностью до токена по сравнению с путем CPU. Большие GEMM Prefill работают на графическом процессоре в
разный порядок накопления, поэтому в **близких логитах** они могут иногда выбирать
другой верхний токен, чем CPU — разница в порядке с плавающей запятой, а не в ядре
ошибка (`make metal-test` проходит GEMM на уровне ~3e-6 при допуске 1e-4; см.
[#622](https://github.com/JustVugg/colibri/issues/622)). Он незаметен при обычном использовании.

побитовое предварительное заполнение (`DEBUG_LOGITS=1` при запуске `TF=1` выводит первые 5 логитов и
поля top1–top2 при каждом несоответствии, чтобы вы могли видеть, насколько близка была ничья).

`COLI_METAL_PREFILL=1` расширяет объединенное внимание до **предварительного заполнения** (S>4): все
внимание — прогнозы, оценки, softmax, значение, вывод — выполняется на графическом процессоре в одном
командный буфер вместо CPU. В промпте из 544 токенов это сокращает внимание к предварительному заполнению.

патологические повторяющиеся подсказки, что ранний токен может перевернуться. Включите его, когда задержка предварительного заполнения
имеет большее значение, чем точная четность CPU; подсказки после падения ограничения потока одной отправки
обратно в процессор автоматически.

```bash
cd c
make colibri METAL=1          # macOS only; no Xcode needed (shader compiles at runtime)
                              # any macOS SDK builds; the COLI_METAL_RESSET residency-set
                              # path needs the macOS 15 SDK and is compiled out below it
make metal-test           # standalone kernel/attention correctness vs CPU reference
COLI_METAL=1 COLI_MODEL=/path/glm52_i4 ./coli chat --ram 96
```

с `METAL=1`: `COLI_METAL=1` (`K3_METAL=1` для Kimi K3) включает серверную часть
нечего строить, и без этого они работают на процессоре, как и раньше.
