## Математика DeltaNet (доказано в numpy без факелов)

Закрытый подуровень DeltaNet (`HF Qwen3_5MoeGatedDeltaNet.forward`,`tools/hf_qwen3_5_moe.py`
для авторитетных источников) по токенам:

1. Проекция: `qkv = x@qkv^T` `[S, conv_dim]`; `z = x@z^T` `[S, value_dim]`; `b=x@b^T`, `a=x@a^T` `[S, vh]`.
2. **Причинная глубинная свертка** (groups=conv_dim, kernel=convk, silu):`conv_out[c] = silu(Σ_kk w[kk]·x_ring[kk] + w[convk-1]·qkv[c])`. `x_ring` — это кольцевой буфер, переносимый по фрагментам (самые последние исходные входные данные `convk-1`), реализующий причинную свертку с левым заполнением.
3. Разрежьте на: `q_in/k_in = conv_out[:2·key_dim_tot]`(`key_dim_tot` каждый), `v_in = conv_out[2·key_dim_tot:]`(`value_dim`).
4. `beta = sigmoid(b)`; `g = -exp(A_log)·softplus(a + dt_bias)` (оба нажмите на головку значения).
5. `q/k` По размеру головы `repeat_interleave` разверните головку `vk` до головки `vh`; ** l2norm** для каждой головы (eps 1e-6 помещается в sqrt), **q умножается на `1/sqrt(kdim)`**, k не умножается.
6. **Рекурсивное закрытое дельта-правило** (каждый заголовок значения `h`, статус `S_h ∈ [kdim, vdim]`):
   `S_h *= exp(g)`; `kv = k·S_h`(длина `vdim`, **векторное скалярное произведение первой оси S**); `delta = (v - kv)·beta`;
   `S_h += k (⊗) delta`(Внешний продукт);`out = q·S_h`.
7. **Gated RMSNorm** (нормальный вес, **нет +1**, среднеквадратичное значение в `/vdim`): `o = (o·rsqrt(mean(o²)+eps))·dn_norm·silu(z)`.
8. `out_proj`:`outr @ dn_out^T` → `[S, hidden]`.

> Ключевая ошибка (уже исправлена перед этапом 2, запишите здесь): в рекурсии вектор должен быть умножен на **первую ось** S.
> (`k·S`, `q·S`), а не `S·k`. Эти два значения случайно равны, только если `kdim==vdim`.
> Gated RMSNorm — это **общий вес** (HF `RMSNormGated` без `+1`), а не `(1+weight)` универсального RMSNorm.

<a id="c-实现cqwen36c"></a>
## Реализация C(`c/qwen36.c`)

- **Новый `deltanet()`**: полностью реализовать вышеперечисленные пункты 1–8, соответствующие проверенным в `tools/_ref_dn_stream.py`.
  `deltanet_stream`(потоковая передача==заполнение,cos≈1,0). `matmul` Проекция одного токена + рукописная рекурсия.
- **Перенос состояния слой за слоем** (вводится в `Model`): `DN_rec[layer]` = рекурсивное состояние `[vh, kdim, vdim]`;
  `DN_conv[layer]` = кольцевой буфер свертки `[conv_dim, convk-1]`. Оба в `step()`
  Чанк предварительного заполнения → токен декодирования сохраняется во всех вызовах (в соответствии с повторяющейся семантикой HF).
- **`Cfg`** Новый `dn_vheads/dn_kheads/dn_kdim/dn_vdim/dn_convk/dn_conv_dim`,
  Считайте (`load_meta`) из поля `dn_*` `qwen36_meta.json`.
- **`Layer`** Добавлен `dn_qkv/dn_z/dn_b/dn_a/dn_conv/dn_dtbias/dn_alog/dn_norm/dn_out`.
- **`step()`**: `continue` больше не пропускает слой DeltaNet. После каждого слоя `rmsnorm(in_ln)`
  `is_attn[i] ? attention() : deltanet()`, остатки, `rmsnorm(post_ln)`, `moe()`.
  Предварительная выборка пилотного проекта изменена на «Пока существует следующий уровень» (теперь каждый уровень имеет MoE).
- **Кэш KV выделяется только для уровня внимания** (DeltaNet использует рекурсивное состояние, не занимает кэш KV и экономит ~2 ГБ для целевых 16 ГБ).
- **Контейнер**: все слои сохраняются в соответствии с **исходным индексом** `model.layers.{i}` (`active_of` теперь является сопоставлением идентификаторов),
  `linear_attn.*` автоматически экспортируется из общей копии `convert_qwen36.py` f16,
  `st_read_f32` автоматически конвертируется в f32. `meta` Имеется `dn_*` полей дополнительных измерений.

<a id="真机gpu-服务器-spark有-gcc-torch"></a>
### Реальная машина (сервер GPU/Spark, с gcc + torch)
```bash
cd c
# 1) HF 预言机:numpy 全前向 vs HF,给出三层 cosine 信号(权威证明 DeltaNet 正确)
python tools/_ref_dn.py --hf ../qwen36_tiny --prompt 1,2,3,4,5
#     [1] LOGIT cos  [1] PER-LAYER cos  [2] DELTANET-ISOLATION cos —— 都应 >0.999

# 2) 编译
make qwen36

# 3) C 引擎 logits dump(与 numpy 同权重,做 torch-free 余弦比对)
SNAP=../qwen36_tiny_i8 DUMP=qwen36_logits.f32 ./qwen36.exe 8 8 ref_qwen36.json
#     -> 写 qwen36_logits.f32 (vocab 个 float32)

# 4) numpy 侧同样 dump(不需要 torch 也能跑前向;torch 只在 [1]/[2] 信号里用)
python tools/_ref_dn.py --hf ../qwen36_tiny --prompt 1,2,3,4,5 --dump ref_logits.f32

# 5) 比对余弦(应 ~0.999+;f16 容器 vs f32 源有微小误差)
python -c "import numpy as np; a=np.fromfile('qwen36_logits.f32',np.float32); b=np.fromfile('ref_logits.f32',np.float32); print('cos=', float(np.dot(a,b)/(np.linalg.norm(a)*np.linalg.norm(b))))"
```

<a id="关于-token-级对齐重要"></a>
### О выравнивании на уровне токена (важно)
Крошечная модель представляет собой **случайно инициализированные веса** (необучающие веса), а сгенерированный жадным образом argmax чрезвычайно чувствителен к ошибкам f16/порядка операций.
**Попадания на уровне токена невозможны при случайных весах** (`ref_qwen36.json` фазы 1 — это ссылка только на внимание,
Механизм фазы 2 вычисляет полную модель, и они больше не согласованы, поэтому не сравнивайте ее с токенами). Правильный критерий: **логиты
Косинус ≥0,999** (шаг 5 выше). При использовании оракула `--mode full` для истинной модели 35B таким же образом посмотрите на косинус.
