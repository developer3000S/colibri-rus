# Справочник по интерфейсу командной строки и настройкам

Настройки командной строки для двух пользовательских программ: **`coli`** CLI и **`openai_server.py`** сервера. Движки внизу (`colibri`, `glm53`, `kimi_k3`, `inkling`, `qwen36`, `qwen38`, `deepseek_v4`, `deepseek_v41`, `olmoe`) управляются переменными среды: см. [ENVIRONMENT.md](ENVIRONMENT.md), где указано, какой движок читает который.

**Обновлено для вклада на основе `upstream/dev @ 21e7a35`** (определения argparse в `c/coli` и `c/openai_server.py`). См. [MAINTAINING-DOCS.md](MAINTAINING-DOCS.md) для регенерации.

---

<a id="coli-the-cli"></a>
## `coli` — интерфейс командной строки

```
coli <subcommand> [flags]
```

Флаги также могут быть заданы **после** подкоманды. Большинство флагов сопоставляются с переменной среды движка до запуска `glm` (см. таблицу сопоставления внизу).

<a id="subcommands"></a>
### Подкоманды

| Подкоманда | Цель |
|---|---|
| `build` | Соберите/подготовьте движок. |
| `info` | Распечатать информацию о модели/сборке. |
| `plan` | Покажите рассчитанный план размещения RAM/VRAM (`--json` для машиночитаемого изображения). |
| `mirror` | Запланируйте, подготовьте или проверьте частичное зеркало модели с ранжированием по использованию (см. [multidisk.md](multidisk.md)). |
| `doctor` | Проверка окружающей среды/здоровья (отчет `--json`, строгая предполетная проверка `--deep`). |
| `tune` | Измерьте и сохраните самый быстрый профиль выполнения с сохранением качества для этой машины/модели. |
| `run "<prompt>"` | Одноразовая генерация для данного промпта (позиционное, может состоять из нескольких слов). |
| `chat` | Интерактивный REPL-чат. |
| `serve` | Запустите HTTP-сервер, совместимый с OpenAI. |
| `web` | `serve`, затем откройте панель управления в браузере. |
| `stop` | Выключите работающий `coli serve` и его механизм (порт по умолчанию: настроенный `coli setup`, иначе `8000`). |
| `setup` | Один шаг: определить оборудование, порекомендовать модель, собрать или загрузить движок (Vulkan/CUDA, если он доступен), загрузить с возобновлением, записать конфигурацию запуска, запустить. Перезапуск начинается сразу после того, как `make` обновил движок с исходными кодами (пересборка только тогда, когда они изменились, как после `git pull`). См. [AI_SETUP.md](AI_SETUP.md). |
| `start` | Запустите то, что настроено `coli setup` (`--background`, `--no-browser`, `--json`). |
| `status` | Что настроено, ход установки, состояние сервера, URL-адреса, идентификатор модели API, tok/s последнего ответа (`--json`). |
| `logs` | Завершение фонового журнала сервера (`-n N`, `--install` для журнала установки). |
| `mcp` | Сервер протокола контекста модели на stdio для помощников по кодированию с использованием искусственного интеллекта. См. [MCP_SERVER.md](MCP_SERVER.md). |
| `cluster coordinator` / `cluster worker` | Управляйте плоскостью управления локального кластера или экспертным работником, который обслуживает ее. |
| `bench [tasks]` | Запустите тестовые задачи (`--limit`, `--data`). |
| `convert` | Преобразуйте репозиторий FP8 в снимок colibrì int4. |

### Общие флаги (все подкоманды)

| Флаг | По умолчанию | Карты | Значение |
|---|---|---|---|
| `--model` | `$COLI_MODEL` или встроенный путь | `SNAP` | Каталог снимков модели. |
| `--ram` | `0` (авто ≈ 88% бесплатно) | `RAM_GB` | Бюджет оперативной памяти в ГБ для экспертного рабочего набора. |
| `--ctx` | `0` (авто) | `CTX` (контекстная переменная семейства) | Длина контекста. Авто, для чат-сервера (`serve`, `web`, `chat`): самый большой из 16384, 32768, 65536, 131072 и 262144 токенов, состояние разговора которых занимает не более четверти памяти до 65536 (агентам кодирования требуется 64 КБ) и десятую часть больше, иначе семейство по умолчанию (DeepSeek V4.1 и MiMo подсчитывают рабочее пространство подсказки с состоянием: V4.1 предварительно заполняет подсказку в одном перенаправлении); `GET /v1/models` сообщает об этом как `context_length` (docs/api.md, «Разговоры длиннее контекста»). || `--cap` | `0` (авто) | `<cap>` аргумент | Ограничение экспертного кэша (начальная точка; см. `CAP_RAISE`). `0` позволяет движку выбирать: `8` исторически, `1` на Metal + macOS, когда объем модели измеряется быстро (зонд F_NOCACHE ≥ `COLI_SSD_FAST_GBS`, кэшируется в `<model>/.coli_ssd` — #379). Явное значение всегда побеждает. |
| `--ngen` | `1024` для `run`; для чат-сервера (`serve`, `web`, `chat`) нет: ответ может доходить до конца контекста | `NGEN` | Максимальное количество токенов для генерации. Очередь модели рассуждения — это рассуждение плюс ответ, поэтому чат-сервер оставляет потолок контексту (#382); `--ngen` устанавливает один. |
| `--temp` | нет (`0`=жадный; версия движка по умолчанию 1.0) | `TEMP` | Температура отбора проб. |
| `--topp` | `0` | `TOPP` | Топ-п фильтр. |
| `--topk` | `0` | `TOPK` | Топ-к фильтр. |
| `--repin` | `0` | `REPIN` | Повторно закрепляйте экспертов каждые N токенов. |
| `--policy` | `quality` | `COLI_POLICY` | `quality` \| `balanced` \| `experimental-fast`. |
| `--gpu` | `None` | `COLI_GPU(S)` | `auto`, `none` или список устройств, например `0,1`. |
| `--vram` | `0` (авто) | план CUDA | Общий бюджет VRAM в ГБ. |
| `--auto-tier` | выключен | план ресурсов | Автоматически применять план размещения RAM/VRAM. |
| `--no-tune-profile` | выключен | профильный погрузчик | Игнорировать сохраненный измеренный профиль. |
| `--think` / `--no-think` | модель по умолчанию | `enable_thinking` в запросе в чат | Рассуждает ли модель, прежде чем ответить. Выключено, подсказка закрывает блок рассуждений, и ответ начинается с первого слова. |
| `--effort` | модель по умолчанию | `reasoning_effort` в запросе в чат | `minimal`, `low`, `medium`, `high` или `xhigh`: как долго модель рассуждает о семьях, которые ее принимают. |
| `--xdna` | выключен | `COLI_XDNA=1` | Экспериментально: выполните квалифицированные операции GLM на процессоре AMD XDNA2 (путь BF16 пониженной точности; выходные данные могут отличаться). |
| `--cluster-workers` | `$CLUSTER_WORKERS` | `CLUSTER_WORKERS` | Экспертные рабочие, разделенные запятыми, `host:port,...`. |
| `--cluster-coordinator` | `$CLUSTER_COORDINATOR` | открытие рабочего | URL-адрес плоскости управления, используемый для обнаружения опытных рабочих. |

## `openai_server.py` — HTTP-сервер

Запустите напрямую (или через `coli serve`). OpenAI-совместимый `/v1/chat/completions`.

| Флаг | По умолчанию | Значение |
|---|---|---|
| `--model` | `$COLI_MODEL` (обязательно, если не установлено) | Каталог снимков модели. |
| `--engine` | `./glm` | Путь к двоичному файлу движка. |
| `--host` | `127.0.0.1` | Привязать адрес. |
| `--port` | `8000` | Порт. |
| `--model-id` | `$COLI_MODEL_ID` или `glm-5.2-colibri` | Идентификатор модели в ответах API. |
| `--api-key` | `$COLI_API_KEY` | Обязательный токен на предъявителя. |
| `--cors-origin` | нет (повторяемый) | Разрешенные источники CORS. Простое значение заменяет список по умолчанию; `+ORIGIN` добавляет к этому. |
| `--allowed-host` | `$COLI_ALLOWED_HOSTS` или нет (повторяемо) | Дополнительный заголовок Host, принимаемый защитой перепривязки DNS. |
| `--cap` | `0` (авто) | Эксперт-кэш-шапка; `0` = движок по умолчанию (`8` или `1` на Metal + macOS + громкость быстрой модели — #379). Без `--cap` профиль `coli tune` или `--auto-tier`, DeepSeek V4.1, MiMo, Qwen3.6 и Qwen3.8 занимают слоты, которые план RAM помещает в доступную при запуске память (`coli plan` распечатывает их). |
| `--max-tokens` | `0` (контекст) | Потолок ответа: запрос без `max_tokens` получает, к нему опускают более крупный. `0`: контекст, который хранит движок. `GET /health` сообщает об этом как `max_tokens`, и веб-интерфейс запускается с него. |
| `--max-queue` | `$COLI_MAX_QUEUE` или `8` | Максимальное количество запросов в очереди. |
| `--queue-timeout` | `$COLI_QUEUE_TIMEOUT` или `300` | Тайм-аут очереди запросов (с). |
| `--kv-slots` | `$COLI_KV_SLOTS` или `1` | Разговорные слоты КВ. |Вызов инструментов поддерживается GLM, DeepSeek V4, Kimi K3, Qwen3.6 и Qwen3.8; Inkling явно отклоняет объявления и варианты активных инструментов, и OLMoE делает то же самое, если только `COLI_TOOL_FALLBACK=1`. См. [матрицу API для каждого движка](api.md#tool-calling-support). Включаемая переменная env `COLI_TOOL_SALVAGE=1` восстанавливает некорректные вызовы инструментов GLM int4; V4 использует собственный синтаксический анализатор DSML. Переменные времени выполнения, специфичные для ядра, перечислены в [ENVIRONMENT.md](ENVIRONMENT.md); сервер передает среду выбранному механизму.

<a id="flags-vs-environment-variables"></a>
## Флаги и переменные среды

Флаг и его сопоставленная переменная среды — это два пути к одной и той же кнопке движка. Приоритет и охват:

- Для ручек с флажком (`--temp`, `--ctx`, `--ram`, `--topk`, `--topp`, `--repin`, `--cap`, `--ngen`, `--policy`) отдавайте предпочтение флажку — это опорная поверхность.
- Для ручек с флагом **no** (`COLI_METAL`, `PIPE`, `DIRECT`, `COLI_NO_OMP_TUNE`, `MLOCK`, `CAP_RAISE`, `KVSAVE`, `SEED`, `NUCLEUS`, …) экспортируйте переменную среды.
- CLI копирует всю вашу среду до `glm`, поэтому любая экспортируемая вами переменная учитывается, если только флаг явно не переопределяет ее.
