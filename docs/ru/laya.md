# Laya в colibri

[Laya](https://huggingface.co/convaiinnovations/laya), компания Convai Innovations
(Apache-2.0) — это модель принятия решений: задайте ей состояние (текст или JSON) и введите
вопросы (`choice`, `score`, `noul`) и отвечает на каждый вопрос с помощью
калиброванные вероятности за один прямой проход. Он никогда не генерирует текст.

`c/laya` запускает его с официальной контрольной точки без конвертации и
`coli serve` выставляет его на `POST /v1/systemone`, тот же запрос и ответ
как Jev API TypeSafe и любая другая модель colibri служит
([systemone.md](systemone.md#decision-engines)).

<a id="download-and-run"></a>
## Загрузите и запустите

Английская контрольная точка — это корень репозитория (842 МБ):

```sh
hf download convaiinnovations/laya model.safetensors rl_agent_config.json \
   "encoder/*" "tokenizer/*" --local-dir ~/Models/laya
make -C c laya
./c/coli serve --model ~/Models/laya
```

`coli` распознает контрольную точку по `rl_agent_config.json` и
`encoder/config.json` кодировщика; нет корня `config.json`, который можно было бы добавить.
`coli info --model ~/Models/laya` показывает кодировщик и бюджет токена,
`coli plan` ОЗУ.

```sh
curl -s localhost:8000/v1/systemone -H 'Content-Type: application/json' -d '{
  "model": "jev-latest",
  "state": "Hi, we were billed twice for March. Please refund the duplicate today or we will cancel our plan.",
  "questions": {
    "department": {"type": "choice", "instructions": "Which department should handle this?",
                   "criteria": {"billing": "invoices, payments, refunds",
                                "technical": "bugs, outages, system errors", "other": "everything else"}},
    "urgency": {"type": "score", "instructions": "How urgent is this?",
                "criteria": ["not urgent", "soon", "blocking"]},
    "churn_risk": {"type": "noul", "instructions": "Does the user threaten to cancel or leave?"}}}'
```

```json
{"id": "req_e622...", "model": "laya", "provider": "colibri",
 "answers": {
   "department": {"type": "choice", "choice": "billing",
                  "probabilities": {"billing": 0.986516, "technical": 0.007975, "other": 0.005509},
                  "confidence": 0.979774},
   "urgency": {"type": "score", "score": 1.772169,
               "legend": {"0": "not urgent", "1": "soon", "2": "blocking"},
               "probabilities": {"0": 0.038904, "1": 0.150022, "2": 0.811074}, "confidence": 0.71661},
   "churn_risk": {"type": "noul", "noul": 0.879019}},
 "usage": {"input_tokens": 164, "output_tokens": 0, "cost": 0}}
```

`input_tokens` — это то, что прочитал кодировщик, учитывается последовательность каждого вопроса.
Чат, завершения и сообщения отвечают на 400 с указателем на `/v1/systemone`,
и `coli chat` говорит то же самое, прежде чем что-либо начинать.

<a id="what-the-engine-computes"></a>
## Что вычисляет движок

Каждый шаг соответствует пакету `laya` (0.3.24), который является справочным:

| шаг | ссылка | в `c/laya.c` |
|---|---|---|
| одна последовательность на вопрос | `common.build_head`, `build_sequence`, `render_options` | `[CLS] <type> question: <instructions> [SEP] [MASK] option ... [SEP] state [SEP]`; опционы ограничены 48 токенами и равномерно сокращаются при переполнении `head_max_len`; состояние сокращается на `max_len`, слева для списка (разговор продолжается) |
| токенизатор | `tokenizer/tokenizer.json` | NFC, добавленные токены разделяются первыми, предварительный токенизатор на уровне байтов GPT-2, BPE (`tok.h`) |
| кодер | СовременныйБЕРТ | 28 слоев предварительной нормы, до внимания слоя 0 нормы нет; RoPE theta 160000 на глобальных слоях (каждый третий, начиная с 0) и 10000 на остальных, которые видят +-64 позиции; ГеГЛУ МЛП; никаких предубеждений; окончательный LayerNorm |
| голова | `DecisionModel.forward` | `+ type_emb[type]`, два слоя преобразователя с нормой (ReLU, 16 головок), скорер (LayerNorm, Linear, GELU, Linear) для каждого варианта `[MASK]` |
| калибровка | `Agent._decode_answers` | одна температура для каждого типа и количества опций (`choice:3-5`, `noul:2`, ...), ограничена значением [0,5, 5], как и пакет (`choice:11+` поставляется 0,1006), softmax по вариантам вопроса |
| глава акта | `DecisionModel.forward` | `[h[0], top1, top1 - top2, entropy, k/255]` -> действовать/эскалировать; содержится в ответе DECIDE, а не в ответе Jev (на карте модели указано, что она еще не несет пригодного для использования сигнала) |

Веса считываются как сохраненные (F16) и сохраняются в f32: 1,7 ГБ ОЗУ. Каждый
вопрос запроса — это один пакет строк; внимание остается внутри каждого
последовательность вопросов.

<a id="checked-against-the-reference"></a>
## Проверено по ссылке

- **Крошечный оракул** (`make -C c laya-tiny-check`, в CI): случайная контрольная точка.
  в макете релиза (`tools/make_laya_tiny.py`, numpy) и что
  `laya` пакет ответов на него (`laya_tiny/ref.json`, автор:
  `tools/make_laya_ref.py`): 12 запросов по 25 вопросов плюс один
  отказ от пакета, охватывающий все типы, от 2 до 20 вариантов, сокращение вариантов,
  длинные состояния и разговоры обрезаются на `max_len`, состояния JSON и
  инструкции, `[MASK]` в тексте, NFC и добавленные токены. Идентификаторы токенов и
  маркеры идентичны, вероятности в пределах 4,8e-7 (допуск 2e-5), каждые
  решение то же; затем тот же прибор до `coli serve`.
- **Настоящие контрольно-пропускные пункты** (`tools/compare_laya.py`): 36 запросов, 117
  вопросы (примеры карточек моделей, пресеты пакета, нарезка документов
  при 512 токенах, вопрос с 40 вариантами, юникод, смайлики). Корневая контрольная точка:
  117/117 решений идентичны, max |dp| 2.7е-6. `typed-decisions`: 117/117,
  макс |дп| 1.2е-6.

<a id="speed"></a>
## Скорость

Измерялось на ноутбуке i7-1355U (10 ядер), 6 потоков у обоих, при другомпроцессов на машине, поэтому цифры смещаются на 20-30% от запуска к запуску:

| | `c/laya` | `laya` пакет (фонарик, CPU, f32) |
|---|---|---|
| 36 запросов, медиана на запрос | 1,9 с | 3,1 с |
| один короткий вопрос (41 токен) | 300 мс | 250 мс |
| Запрос README, 3 вопроса, до `coli serve` | 882 мс, из них 2,5 мс на шлюзе | |
| Запрос Джева, 1 вопрос, до `coli serve` | 219 мс, из них 2,5 мс на шлюзе | |

Движок идет впереди, когда в запросе несколько вопросов, и немного отстает
на одном коротком. Варианта int8 нет: мерил на том же 117
вопросы, веса int8 изменили 1 решение и веса int8 с int8
активации изменились 4, что не является сделкой, которую должна совершать модель принятия решений.

**На устройстве CUDA** (сборка `CUDA=1`, `coli serve --gpu` или `COLI_CUDA=1`): кодировщик и
голова работает на карте, матрицы в f32 (docs/cuda.md "Движки принятия решений"). РТХ
PRO 4000 против процессора своего хоста (i5-13500, 6 потоков), запросы 12 вопросов в течение
Электронное письмо длиной 1700 символов (по 6144 строк каждое): 0,69 с на запрос против 11,4–13,0 с у процессора
решения, каждая вероятность в пределах 3,3e-6 процессоров.

<a id="knobs"></a>
## Ручки

| переменная | по умолчанию | смысл |
|---|---|---|
| `COLI_LAYA_MAX_LEN` | GGUF `max_len` (512) | токены за последовательность вопросов; энкодер читает до 8192 |
| `COLI_LAYA_HEAD_MAX_LEN` | GGUF `head_max_len` (192) | токены, общие для инструкций и опций; поднять его для многих вариантов |
| `OMP_NUM_THREADS` | физические ядра | что касается других движков |

Вопрос, варианты которого не подходят, отклоняется с кодом 422, в котором указано, сколько
Маркеры подходят, так как упаковка от них отказывается.

<a id="the-other-checkpoints"></a>
## Остальные контрольно-пропускные пункты

- **`typed-decisions/`** (та же архитектура, доработанная, `max_len` 1024):
  укажите `--model` на подпапку. Проверил как указано выше.
- **`multilingual/`** (`laya-multilingual`, ммBERT-база, 22 слоя x 768,
  словарь (256 тыс.) пока не поддерживается. Что для этого нужно: стиль в стиле SentencePiece.
  BPE (предварительный токенизатор `Metaspace`, нормализатор `Replace`, резервный байт,
  580k объединяется) в токенайзере, `<bos>`/`<eos>`/`<mask>` как специальный
  токены, RoPE 160000 на каждом уровне (обе теты в его конфигурации) и
  длинный контекст по умолчанию (`max_len` 1024, до 8192). Кодер и голова
  в противном случае это код выше; в реестре уже есть имя
  (`Laya multilingual`, идентификатор модели `laya-multilingual`).

<a id="limits"></a>
## Ограничения

- На этом контрольно-пропускном пункте только английский язык: карточка модели измеряет его, когда она разваливается.
  нелатинскими буквами, сохраняя при этом уверенность.
- Отгруженные температуры подобраны по данным авторов; карточка модели
  советует переоборудовать на свой. colibri применяет собственные значения контрольной точки.
- `noul` может следовать меткам своих опций, а не состоянию на этом
  GGUF (карточка модели); два варианта `choice` с нейтральными клавишами — это
  обходной путь, который они дают.
