<a id="当前范围"></a>
## Текущая область действия

- Производственный код — `c/deepseek_v4.c`, экспериментальный общедоступный API движка/сессии — по адресу.
  `c/deepseek_v4.h`.
- Официальная контрольная точка Shard Safetensors загружается через общий ресурс `st.h`.
- Стандартное умножение матриц MXFP4 использует общий `quant.h`.
- Единый вход `c/coli` проведет `run`, `chat`, `serve`, `web` к V4,
  Режим обслуживания сохраняет механизм и кеш между запросами.
- `--no-dspark` Просто отсутствие совместимости. В этом PR нет моделей DSpark, иерархии памяти или спекулятивных циклов.
- Поддерживает x86-64, aarch64 Linux и Windows/MSYS2.

Все сеансы должны быть уничтожены перед уничтожением движка.

<a id="内存策略"></a>
## Стратегия памяти

Типичная контрольная точка имеет 43 слоя преобразователей, скрытый размер 4096, и каждый разреженный слой имеет
256 экспертов маршрутизации, top-k — 6. Плотные веса занимают примерно 6,27 ГиБ, резидентный выход BF16.
head занимает примерно 1,06 ГиБ; Экспертные веса маршрутизации передаются в потоковом режиме и кэшируются в соответствии с бюджетом оперативной памяти.

Планировщик сначала резервирует рабочее пространство и минимальный рабочий набор экспертов, а затем включает плотного/главного резидента, когда позволяет бюджет.
и расширить экспертный кэш. Dense resident и DSpark независимы друг от друга. В текущей целевой версии и
Старый абонент будет работать нормально при передаче `--no-dspark`.

`--ram GiB` — это плановый бюджет, а не жесткий верхний предел операционной системы; если он не передан, он оценивается на основе текущей доступной памяти.

<a id="构建与使用"></a>
## Сборка и использование

```bash
cd c
make deepseek-v4
python ./coli run --model /path/to/DeepSeek-V4-Flash --ram 32 \
  "What is the capital of France?"
python ./coli chat --model /path/to/DeepSeek-V4-Flash --ram 32
python ./coli serve --model /path/to/DeepSeek-V4-Flash --ram 32
python ./coli web --model /path/to/DeepSeek-V4-Flash --ram 32
```

Чат V4 использует собственную разметку модели. Собственный сервис в настоящее время поддерживает жадный и активный слот KV.
HTTP-шлюз преобразует инструменты OpenAI и Anthropic в собственный протокол подсказок V4.
Затем проанализировать блок вызовов DSML обратно в соответствующий протокол; грамматика по-прежнему не поддерживается. См.
[Таблица поддержки API каждого движка](api.md#tool-calling-support). Запросы будут повторно использовать строго соответствующее промпт.
Префикс, вводите только новый суффикс; когда промпт разветвляется, оно будет предварительно заполнено с самого начала. Процесс, вес, плотность,
Тайники с головами и экспертами остаются горячими.
